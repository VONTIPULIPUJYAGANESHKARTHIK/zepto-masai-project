# Analytics Module

This module implements the analytics pipeline that profiles and models a customer-style dataset end to end.

## Workflow

1. **Data Loading**: The Jupyter Notebook reads the cleaned data directly from the SQLite database (`zepto.db`) generated by the data pipeline.
2. **Exploratory Data Analysis (EDA)**: We perform data profiling and create visualizations using `matplotlib` and `seaborn`. This includes mapping the distribution of delivery times and analyzing the impact of external conditions like weather and traffic.
3. **Predictive Modeling**: 
   - We establish a baseline using a standard **Linear Regression** model.
   - We train a more advanced **Random Forest Regressor** to predict delivery times (`delivery_time_mins`) based on distance and weather conditions.
   - We utilize **`GridSearchCV`** for hyperparameter tuning to find the optimal configuration for the Random Forest.
4. **Evaluation**: The models are evaluated using Mean Absolute Error (MAE) and R-squared. We also extract and visualize the **Feature Importances** to understand which variables drive the model's decisions.

## Execution

Open the Jupyter Notebook and execute all cells:
```bash
jupyter notebook analytics/analytics_end_to_end.ipynb
```
