# Zepto Data & AI Platform Capstone

This repository contains the end-to-end Zepto Data & AI Platform implementation, which includes three modules:
1. `/data_pipeline`: Data engineering pipeline that turns raw scraped data into a clean relational store.
2. `/analytics`: Analytics pipeline that profiles and models a customer-style dataset end to end.
3. `/support_assistant`: GenAI support assistant that answers policy questions grounded in Zepto's documents.

## Setup Instructions

A consolidated `requirements.txt` is provided in the root directory for all three modules. 
To install the dependencies, create a virtual environment and run:

```bash
pip install -r requirements.txt
```
